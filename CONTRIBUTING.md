# Contributing to Awesome Websites

Thank you for your interest in contributing to Awesome Websites! This guide will help you understand how to contribute effectively.

[中文版贡献指南](CONTRIBUTING_CN.md) | English

## How to Contribute

### 1. Suggesting a New Website

Before suggesting a new website, please:

1. **Search existing entries** to make sure the website isn't already listed
2. **Check if it fits our quality standards** (see below)
3. **Test the website** to ensure it's functional and provides value

#### Quality Standards

We accept websites that:
- ✅ Are actively maintained and functional
- ✅ Provide genuine value to users
- ✅ Have a clear purpose and good user experience
- ✅ Are accessible and load reasonably fast
- ✅ Are not primarily promotional or spam
- ✅ Are available in English or have English interface/documentation

We typically don't accept:
- ❌ Websites that are down or broken
- ❌ Pure promotional/marketing pages
- ❌ Malicious or unsafe websites
- ❌ Websites requiring paid registration to access basic features
- ❌ Duplicate entries or very similar services already listed

### 2. Submission Process

#### Option A: Create an Issue
1. Go to [Issues](https://github.com/[YOUR_USERNAME]/awesome-websites/issues)
2. Click "New Issue"
3. Use the website suggestion template
4. Fill in all required information

#### Option B: Submit a Pull Request
1. Fork this repository
2. Create a new branch (`git checkout -b add-website-name`)
3. Add your website to the appropriate category in both `README.md` and `README_CN.md`
4. Follow the format: `- [Website Name](URL) - Brief description`
5. Commit your changes (`git commit -am 'Add Website Name'`)
6. Push to the branch (`git push origin add-website-name`)
7. Create a Pull Request

### 3. Formatting Guidelines

#### Website Entry Format
```markdown
- [Website Name](https://example.com) - Brief description of what the website does
```

#### Guidelines:
- **Website Name**: Use the official name as it appears on the site
- **URL**: Use the main/homepage URL, prefer HTTPS when available
- **Description**: Keep it concise (under 100 characters), describe the main purpose/value
- **Categories**: Place in the most relevant category, create new categories if needed

#### Example:
```markdown
- [Figma](https://www.figma.com/) - Collaborative interface design tool
```

### 4. Translation Requirements

When adding a website, please provide entries for both:
- English version in `README.md`
- Chinese version in `README_CN.md`

Ensure descriptions are appropriately translated, not just literal translations.

### 5. Category Guidelines

#### Existing Categories:
- **AI Tools**: AI-powered applications and services
- **Games & Entertainment**: Online games and entertainment platforms
- **Development Tools**: Programming and development resources
- **Design Resources**: Design tools, assets, and inspiration
- **Learning Resources**: Educational content and tutorials
- **Productivity Tools**: Apps and tools for improving productivity
- **Search Engines**: Search platforms and specialized search tools
- **Data Analytics**: Data visualization and analytics platforms
- **Other Useful Sites**: Utilities and miscellaneous useful websites

#### Adding New Categories:
If your website doesn't fit existing categories:
1. Suggest a new category in your PR/Issue
2. Provide at least 3 websites for the new category
3. Use appropriate emoji icons for consistency

### 6. Review Process

1. **Initial Review**: Maintainers will check if the website meets quality standards
2. **Testing**: We test the website for functionality and value
3. **Formatting**: Check if the entry follows formatting guidelines
4. **Approval**: If everything looks good, the entry will be merged

### 7. Maintenance

Help us maintain the list by:
- **Reporting broken links** via Issues
- **Suggesting updates** to descriptions or categorizations
- **Removing outdated entries** that are no longer relevant

## Code of Conduct

Please be respectful and constructive in all interactions. We welcome contributions from everyone regardless of experience level.

## Questions?

If you have questions about contributing, feel free to:
- Open an Issue with the `question` label
- Check existing Issues for similar questions

Thank you for helping make this resource better for everyone!
